# Changelog

## 0.1.0

The first version of Baseline, the home for Gridline and Pixelline.

- **Home:** start a blank spreadsheet or image, or a favourite preset, and reopen recent files from both apps.
- **Create:** every Gridline preset (budgets, loans, portfolios, sports, planning) and Pixelline sizes (Minecraft textures and skins, sprites, icons, photos).
- **Files:** recent files from Gridline and Pixelline together, with pictures of images, filters, search (Ctrl+K) and pins. Click to open a file in the right app; Ctrl+O opens any file.
- **Installs the other apps:** the first time Baseline starts after being installed, it downloads and installs Gridline and Pixelline from their release pages (for your Windows user, no admin rights needed), with the progress on Home. The portable Baseline offers to instead.
- **Updates for every app:** Baseline checks Gridline and Pixelline for updates when it starts and every few hours, shows what's new, and updates them in one click, or automatically if you turn it on. Settings → Apps can switch the apps to their development builds.
- **Apps:** what is installed and its version; open, install or update each app. Portable copies can be set in Settings.
- Dark and light themes, accent colours, start with Windows, automatic updates and the Developer branch.
